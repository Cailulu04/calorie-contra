# Calorie Contra

Calorie counter and food search web app with USDA search, food log, profile calorie goals, Gemini chatbot, and photo-based food recognition.

## Run locally

1. **Clone**

   ```sh
   git clone https://github.com/jericho1050/calorie-contra.git
   cd calorie-contra
   ```

2. **Virtual environment**

   ```sh
   python -m venv env
   source env/bin/activate   # Windows: .\env\Scripts\activate
   ```

3. **Dependencies**

   ```sh
   pip install -r requirements.txt
   ```

4. **Environment variables**

   Copy `.env.example` to `.env` and set:

   - `SECRET_KEY` — random string for sessions
   - `USDA_API_KEY` — [USDA FDC API key](https://fdc.nal.usda.gov/api-key-signup.html)
   - `gemini_api_key` — [Google AI Studio](https://aistudio.google.com/apikey) (chat & image features)

5. **Start server**

   ```sh
   python app.py
   ```

   Open **http://127.0.0.1:5001** (port 5001 avoids macOS AirPlay on 5000).

## Deploy for users (public URL)

This is a **Quart (Python) backend** — [GitHub Pages](https://pages.github.com) cannot run it. Use **Render** (free):

1. Push this project to **your** GitHub account (see [Publish to GitHub](#publish-to-github) below).
2. Sign in at [render.com](https://render.com) with GitHub.
3. **New → Blueprint** → select your repo → Render reads `render.yaml`.
4. In the Render dashboard, add environment variables (same as `.env`):
   - `gemini_api_key`
   - `USDA_API_KEY`
   - `SECRET_KEY` is auto-generated by the blueprint; you can leave it or set your own.
5. After deploy, copy the URL (e.g. `https://calorie-contra-xxxx.onrender.com`) and share it. Add it to the **Live app** row in this README.

**Note:** Free Render apps sleep after inactivity; the first visit may take ~30s to wake. Gemini may block some regions — use a supported region or VPN for API calls.

## Publish to GitHub

If this folder is not on your account yet:

```sh
# Create an empty repo on github.com (no README), then:
git remote set-url origin https://github.com/YOUR_USERNAME/calorie-contra.git
git add .
git commit -m "Add profile, Gemini features, and Render deployment"
git push -u origin main
```

If you forked the original repo, push to your fork and enable GitHub Pages only if you add a static site later — the app itself still needs Render (or Railway / Fly.io) for the live link.

## Main routes

| Route | Description |
|-------|-------------|
| `/home` | Food search (USDA) |
| `/profile` | Calorie goals & workout estimates |
| `/food-log` | Daily food log |
| `/login`, `/register` | Accounts |
| `POST /generate` | Chatbot |
| `POST /api/analyze-image` | Photo food recognition |
